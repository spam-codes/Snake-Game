Functionalities:\n
-> Start Game Button ( A pop-up at the starting)
-> Restart Game Button ( A pop-up )
-> Pause Game Button
-> Resume Game Button
-> Help Button ( Gives a pop-up)
-> High Score saving in the browser local storage
-> Proper timer working
